# LAE Secret Chat – öffentliche APK-Releases

Dieses Repository enthält ausschließlich installierbare APK-Builds und Update-Metadaten der Android-App.

Der eigentliche Quellcode bleibt in einem separaten privaten Repository.

## Dateien

- `releases/LAE-Weather-latest.apk` – immer die aktuellste installierbare APK
- `releases/LAE-Weather-<version>-dev.apk` – versionierte Vorab-Builds
- `version.json` – Versionsinformationen für die spätere In-App-Updateprüfung

## Installation

Die APK kann direkt auf einem Android-Gerät installiert werden. Bei späteren Versionen mit derselben Signatur kann die vorhandene App aktualisiert werden, ohne sie vorher zu deinstallieren.

## Hinweis

Die Builds sind derzeit Development-/Preview-Versionen und nicht für den Google Play Store bestimmt.
